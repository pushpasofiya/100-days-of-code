# Day 1

## Problem
Two Sum

## LeetCode Number
1

## Difficulty
Easy

## Pattern
Hashing

## Approach
I used an unordered_map to store the elements
that I have already seen.

For every element, I check whether
target - current element already exists.

## Time Complexity
O(n)

## Space Complexity
O(n)

## Mistake I Made
I initially thought about using a brute-force
nested loop solution.

## What I Learned
I learned how hashing can reduce the search
from O(n²) to O(n).
